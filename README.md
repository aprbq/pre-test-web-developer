# Pre Test Web Developer - User form

โปรเจกต์ระบบจัดการข้อมูลผู้ใช้ พัฒนาด้วย React (Frontend only)

### รันโปรเจกต์
1. **Clone โปรเจกต์**

    ```bash
    git clone https://github.com/aprbq/pre-test-web-developer.git
   ```

2. **ติดตั้ง Dependencies ทั้งหมด**
   ```bash
   cd pre-test-web-developer
   npm install
   ```

3. **รันเซิร์ฟเวอร์**
   ```bash
   npm run dev
   ```

4. เปิดเบราว์เซอร์แล้วเข้าไปที่ [http://localhost:5173](http://localhost:5173)
